This document says what is built, not how. The user stories are the source of truth: anything not traceable to a story is out of scope.

## Summary

An operations user sees every inspection with its status, vehicle registration and customer name, and opens one to see its details. The same list and single inspection are available through the API.

## User stories

| ID | Story |
|---|---|
| US-201 | As an API client, I can list all inspections. |
| US-202 | As an API client, I can retrieve one inspection by its ID, and I get a clear error if it does not exist. |
| US-203 | As an operations user, I can see all inspections on a web page with their status, vehicle registration and customer name, so that I know the progress of each. |
| US-204 | As an operations user, I can select an inspection to see its details. |

## Acceptance criteria

API criteria are covered by automated tests. UI criteria are checked by hand.

| ID | Story | Criterion |
|---|---|---|
| AC-201 | US-201 | The list returns all inspections, newest first. |
| AC-202 | US-201 | With no inspections, the list returns 200 and an empty list. |
| AC-203 | US-202 | Retrieving by ID returns that inspection. |
| AC-204 | US-202 | An unknown ID returns 404 as JSON with a `message`. |
| UI-201 | US-203 | The page lists each inspection with its status, vehicle registration and customer name. |
| UI-202 | US-203 | While the list is loading, the page says so. |
| UI-203 | US-203 | With no inspections, the page says there are none. |
| UI-204 | US-203 | If the list cannot be loaded, the page shows an error. |
| UI-205 | US-204 | Selecting an inspection shows its customer name, vehicle registration, requested date, notes, status and inspector name. |

## Screen

One page with two panels. The left panel lists inspections, one row each, showing status, vehicle registration and customer name. Selecting a row marks it as selected and shows that inspection in the right panel. Before a row is selected, the right panel asks the user to select one.

## Out of scope

From the brief: authentication, payments, photo uploads, notifications, deployment.

Not in any story, so not built: search, filtering, sorting controls and pagination.

## Assumptions

| ID | Assumption |
|---|---|
| A-201 | There is no authentication, so any caller may view any inspection. |
| A-202 | The list is ordered newest first so that the order is stable. |
| A-203 | The list returns every inspection in one response. |
